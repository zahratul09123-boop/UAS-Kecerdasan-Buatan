# 🧬 Tugas Algoritma Genetika - Penjadwalan Kuliah

## 📌 Deskripsi
Program ini dibuat untuk menyusun jadwal kuliah secara optimal menggunakan **Algoritma Genetika (Genetic Algorithm)**.

Algoritma ini bekerja dengan cara:
- Membuat populasi jadwal secara acak
- Menghitung nilai fitness (kualitas jadwal)
- Melakukan seleksi, crossover, dan mutasi
- Menghasilkan solusi terbaik dengan konflik minimum

---

## 🎯 Tujuan
Menghasilkan jadwal kuliah yang:
- Tidak bentrok antar mata kuliah
- Tidak bentrok penggunaan ruang
- Tidak bentrok jadwal dosen

---

## ⚙️ Cara Kerja Singkat
1. Inisialisasi populasi jadwal
2. Evaluasi fitness tiap individu
3. Seleksi individu terbaik
4. Crossover (perkawinan solusi)
5. Mutasi (perubahan acak)
6. Ulangi sampai mendapatkan solusi optimal

---

## 📊 Hasil
- Grafik menunjukkan peningkatan nilai fitness dari generasi ke generasi
- Nilai fitness mendekati maksimum (≈100)
- Jadwal akhir tidak memiliki konflik
